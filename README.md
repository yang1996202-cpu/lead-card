# Lead Card - 销售线索卡片生成器

一个 Claude Code Skill，帮你把公司名变成一张结构化的客户卡片。

## 它能做什么？

**输入：** 一个公司名（如"易点云"）

**输出：** 一张客户卡片，包含：

1. **公司画像** - 行业、规模、营收、融资
2. **关键人信息** - 老板、核心高管背景
3. **公司动态** - 招聘活跃度、近期新闻
4. **行业洞察** - 行业现状、行业痛点
5. **破冰谈资建议** - 开场白方向、可能的痛点、联系优先级

## 为什么需要它？

销售筛线索时，需要查企查查、看官网、看招聘、看新闻。

这些信息分散在 4 个地方，每次都要花 10-20 分钟。

**Lead Card 把这个流程压缩到 30 秒。**

## 安装

### 前置要求

1. **Claude Code** - Anthropic 官方 CLI 工具
2. **Tavily API Key** - 用于搜索（免费额度足够个人使用）

### 安装步骤

```bash
# 1. 克隆或下载 skill 到你的 Claude Code skills 目录
mkdir -p ~/.claude/skills/lead-card
# 将 SKILL.md 放到 ~/.claude/skills/lead-card/

# 2. 配置 Tavily API Key
export TAVILY_API_KEY="your-api-key-here"
# 或添加到 ~/.zshrc / ~/.bashrc

# 3. 重启 Claude Code
claude
```

## 使用方式

```bash
# 基础用法
/lead-card 易点云

# 指定输出路径
/lead-card 易点云 --output 03_归档/客户/

# 结合你的业务生成针对性谈资
/lead-card 易点云 --my-product IT设备租赁服务
```

## 设计理念

这个工具的核心价值不是"数据"——企查查、天眼查都有数据。

核心价值是：
- **整合**：把分散在 4 个平台的信息整合到一张卡片
- **解读**：用销售视角解读这些信息意味着什么
- **建议**：生成可执行的谈资建议

这是 6 年 B 端销售经验的方法论沉淀。

## 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `公司名` | 必填，目标公司名称 | `易点云` |
| `--output` | 可选，指定卡片保存路径 | `--output 03_归档/` |
| `--my-product` | 可选，你的业务，用于生成针对性谈资 | `--my-product 企业培训` |

## 数据来源

- 企查查/天眼查 - 公司基本信息
- 官网 - 产品、业务方向
- 招聘网站 - 公司活跃度
- 新闻/舆情 - 行业动态
